# Practical 7: Operating System Simulator

## Aim
To use an operating system simulator to simulate
operating system tasks.

## Software Used
OScope Online Operating System Simulator

## Procedure
1. Opened the OScope simulator in a web browser.
2. Selected the Process States simulation.
3. Loaded the example scenario.
4. Observed the process state diagram.
5. Stepped through the simulation using the
   keyboard arrow keys.
6. Observed the transitions between process states.

## Process States
- New
- Ready
- Running
- Waiting
- Terminated

## Result
The operating system process states were
simulated and observed using OScope.
